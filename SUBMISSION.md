# Submission checklist

These steps from the PDF have to be done by you on your own accounts:

- [ ] Create a GitHub repository and push this folder (see `level-1/SETUP.md` → Git and GitHub)
- [ ] Deploy Level 3 (see `level-3/README.md` → Deploy to Render) and add the live URL to the README
- [ ] Record a short video (2–4 min) for each level: what you built, a live demo, one interesting piece of code
- [ ] Post on LinkedIn with the video + GitHub link, tag **@Codveda**
- [ ] Add the offer letter and the completion certificate to your LinkedIn profile
- [ ] Submit through the Codveda submission form when it is shared (within 1 month)

## Video outline (per level)
1. **Intro (15s):** name, Codveda Full-Stack internship, level number
2. **What I built (30s):** the two tasks and the stack
3. **Live demo (1–2 min)**
   - L1: CRUD in the UI, validation errors, Thunder Client requests
   - L2: register/login in Thunder Client, 403 on an admin route, search/pagination, `npm test`
   - L3: two browser windows showing a live task move, chat, DM, notification toast and the admin page
4. **Code highlight (30s):** e.g. auth middleware, MongoDB indexes, the Socket.io room design
5. **Outro (10s):** GitHub link and what you learned
